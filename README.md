# 知行日志 v3 · 安装与 GitHub 操作步骤

一个可以装到 iPhone、iPad、安卓主屏幕上的习惯与待办应用：

- **清单**（参考 Things 3 的组织方式）：收集箱、今天（含今晚）、计划、随时、将来、日志簿；领域与项目；点一下任务就地展开编辑。
- **练习**：习惯打卡、专注计时、复习卡片、周/月回顾（含「完整度」与计划校准）。
- **每日省察**：上午的「晨省」（今天最重要的一件事、阻碍与对策），傍晚的「晚省」（做成了什么、哪里没做好、漏了什么、此刻的感受）。
- **依据**：60 条来源——行为科学研究（标注证据强弱和 DOI），以及中国、希腊、罗马的古典教育思想和荣格的自性化（标注为「思想传统」）。
- **多人**：每人一份私密记录；小组里互看每周完成情况、互相鼓掌；共享项目里可以把任务指派给别人。
- **数据**：全部存在你自己的 GitHub 私有仓库里，每次保存都是一次提交，可以随时下载、找回历史版本。

---

## 数据放在哪里

```
zhixing-data（你的私有仓库）
└── zhixing/
    ├── users/
    │   ├── u7k2a9x.json   ← 阿杰的个人记录
    │   └── uq81mzt.json   ← 小林的个人记录
    └── group/
        └── team.json      ← 成员名单、每周进度、共享项目、鼓掌
```

应用只显示你自己的个人记录；小组里能看到的，只有每周完成数（可以关闭分享）和共享项目。

## 一、仓库主人：第一次设置（约 10 分钟，只做一次）

### 第 1 步 · 建数据仓库（私有）

1. 登录 [github.com](https://github.com)，点右上角 **+** → **New repository**。
2. **Repository name** 填 `zhixing-data`。
3. 选 **Private**。
4. 勾选 **Add a README file**。
5. 点 **Create repository**。

### 第 2 步 · 建应用仓库，上传文件，开启网页

1. 再点右上角 **+** → **New repository**，名字填 `zhixing`，选 **Public**（这里只放程序文件，不放任何记录）。勾选 **Add a README file**，创建。
2. 先在电脑上解压 `知行日志-v3.zip`。
3. 在 `zhixing` 仓库页面点 **Add file** → **Upload files**，把 `zhixing-app` 文件夹**里面的所有文件**拖进去：
   `index.html`、`sw.js`、`manifest.webmanifest`、4 个 `.png` 图标（`README.md` 和 `.nojekyll` 可传可不传）。
4. 点 **Commit changes**。
5. 打开仓库的 **Settings** → 左侧 **Pages**：
   - **Source** 选 **Deploy from a branch**
   - **Branch** 选 **main**，文件夹选 **/ (root)**，点 **Save**
6. 等 1–2 分钟后刷新这个页面，顶部会出现网址：`https://你的用户名.github.io/zhixing/`。这就是应用的地址。

> 只用 iPhone/iPad、没有电脑？在手机上的「文件」App 里点一下 zip 就能解压；GitHub 网页的 Upload files 也可以在 iPad 的 Safari 里用。

### 第 3 步 · 创建访问令牌（让应用能读写数据仓库）

1. 打开 <https://github.com/settings/personal-access-tokens/new>
   （也可以：头像 → **Settings** → 最下面 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**）。
2. **Token name**：填「知行日志」。
3. **Expiration**：选一个较长的期限。到期前 GitHub 会发邮件提醒，到时按「八、更换令牌」处理。
4. **Repository access**：选 **Only select repositories**，只勾 `zhixing-data`。
5. **Permissions** → **Repository permissions** → 找到 **Contents**，改成 **Read and write**。其他不用动。
6. 点 **Generate token**，复制 `github_pat_` 开头的那串字符。它只显示这一次，先存进备忘录。

### 第 4 步 · 装到手机或 iPad 上，连接仓库

1. 用 **Safari** 打开第 2 步得到的网址。
2. 点分享按钮 → **添加到主屏幕**。
3. **从主屏幕的图标打开**应用。在 iOS 上，主屏幕应用和 Safari 的存储是分开的，所以下面的设置要在应用里做。
4. 点「开始使用」→「创建小组（我是仓库主人）」，填写：
   - 你的名字（小组里显示）
   - GitHub 用户名
   - 数据仓库名：`zhixing-data`
   - 刚才复制的令牌
5. 点「连接」。看到「已连接」就完成了。左下角（iPad）或右上角头像上的圆点变绿，表示已同步。

### 第 5 步 · 你自己的第二台设备（比如手机 + iPad）

两种方法任选一种：

- **方法一**：在第二台设备上重复第 4 步，**名字填得和第一台一模一样**，应用会自动认出是你，两台设备共用一份记录。
- **方法二**：在第一台设备上，打开「我与设置」→「在另一台设备上用」，复制设备码。在第二台设备上点「开始使用」→「我收到了邀请码」，粘贴设备码即可。

## 二、邀请家人朋友（每人一次）

**你这边：**

1. 应用里打开「小组」→「邀请成员」，输入 TA 的名字，点「生成邀请码」。
2. 点「复制邀请码」，用微信等方式**私下**发给 TA，同时把应用网址也发过去。

**TA 那边**（不需要 GitHub 账号）：

1. 用 Safari 打开应用网址 → 分享 → **添加到主屏幕**，然后从主屏幕图标打开。
2. 点「开始使用」→「我收到了邀请码」，粘贴，确认名字，点「加入」。

加入之后，TA 会出现在「小组」里。你们可以：

- 互相看到每周的打卡率、完成数、专注时长和复习次数（每人都可以在小组页关掉分享）；
- 给对方「鼓掌」，对方下次打开应用会看到提示；
- 建共享项目（比如「周末大扫除」「读书会」），把任务指派给某个人。指派给你的任务会出现在你的「今天」或「计划」里。

## 三、隐私说明（请一定读一下）

- 每个人的个人记录在自己的文件里，应用只读取和显示自己的那一份。
- 但大家用的是**同一个令牌**（它包含在邀请码里）。技术上，拿到邀请码的人可以通过 GitHub 接口读写整个数据仓库，包括别人的文件。所以**只邀请你信任的人**，邀请码只私下发。
- 数据仓库一定要是 **Private**。如果连接时提示「这个仓库是公开的」，去仓库 **Settings** → 最下面 **Change repository visibility** 改成 Private。

## 四、日常使用要点

- **右下角的 +**：在当前清单里新建任务。在「今天」里新建的就是今天的任务，在某个项目里新建的就属于这个项目。
- **点一下任务**：就地展开，可以写备注、拆步骤（第一步就是「下一步」），设置时间、截止日期、归属、重复、预计轮数；「…」里可以写为什么重要、如果……就……、上次停在哪。
- **时间**：今天 / 今晚 / 明天 / 某一天 / 将来。不定时间但已归类的事在「随时」里。
- **收集箱**：想到什么先丢进来，回头再整理。专注时的「分心停车场」也会存到这里。
- **卡住了？**：「今天」页任务标题旁边。先说出感受，再拿到一个具体的启动办法，然后只做 5 分钟。
- **iPad 键盘**：⌘K 搜索，Esc 关闭，回车完成编辑；复习时空格翻面，1–4 打分。

## 五、同步是怎么工作的

- 改动先保存在设备上，大约 5 秒后同步到 GitHub；打开或切回应用时、使用中每 90 秒也会同步一次。
- 没网时照常使用，联网后自动补上。
- 几台设备、几个人同时修改时：同一条记录以最后修改为准；专注记录、复习次数、习惯打卡会合并，不会互相覆盖；删除也会同步。
- 圆点颜色：绿色＝已同步，黄色＝同步中或等待联网，红色＝出错（点头像进「我与设置」看原因）。

## 六、下载数据

- **应用里**：「我与设置」→「下载」，有四种文件：
  - JSON 备份：完整数据，可以再导入
  - 每日汇总 CSV：每天的专注、完成、习惯、复习
  - 任务 CSV、专注记录 CSV：明细
  CSV 能直接用 Excel 或 Numbers 打开。在 iPhone/iPad 上会弹出分享面板，选「存储到文件」即可。
- **GitHub 上**：打开 `zhixing-data` 仓库 → `zhixing/users/你的文件.json` → 右上角下载按钮；或在仓库首页点 **Code** → **Download ZIP** 下载全部。
- **找回历史版本**：在 GitHub 打开某个 `.json` 文件 → 右上角 **History**，可以看到每一次保存。

## 七、更新应用

1. 在 `zhixing` 仓库首页点 **Add file** → **Upload files**，上传新的 `index.html`（同名文件会被覆盖），**Commit changes**。
2. 打开 `sw.js`，点铅笔图标编辑，把第 2 行的版本号加 1（比如 `zhixing-v3.1` 改成 `zhixing-v3.2`），**Commit changes**。
3. 手机上把应用完全关掉再打开一两次，就会换成新版本。记录不受影响。

---

## 八、更换令牌（令牌到期，或怀疑泄露）

1. 在 GitHub 的 Fine-grained tokens 页面删除旧令牌，按「第 3 步」生成一个新的。
2. 在你的应用里：「我与设置」→「更新令牌」，粘贴新令牌。
3. 你自己的其他设备：同样「更新令牌」，或用「在另一台设备上用」重新发设备码。
4. 其他成员：在「小组」→「邀请成员」里输入 TA **原来的名字**重新生成邀请码。应用会认出这是已有成员，新邀请码会接着使用 TA 原来的记录。TA 在「开始使用」→「我收到了邀请码」里重新粘贴即可。

---

## 九、从旧版本搬数据

claude.ai 里的版本，或之前的独立版：在旧版「设置」里点「导出备份」，得到一个 `.json` 文件。然后在新版「我与设置」→「导入备份」选择它。旧格式会自动转换（「第一步」和「拆分步骤」会变成新版的步骤清单）。

## 十、常见问题

| 提示 | 怎么办 |
|---|---|
| 找不到这个仓库 | 检查 GitHub 用户名和仓库名；确认令牌的 Repository access 选中了 `zhixing-data` |
| 没有写入权限 | 令牌的 Contents 要设为 **Read and write** |
| 令牌无效或已过期 | 按「八、更换令牌」处理 |
| 手机和 iPad 的记录不一样 | 确认两台设备用的是同一个名字，或用「在另一台设备上用」的设备码 |
| 加到主屏幕后又要重新设置 | iOS 上主屏幕应用和 Safari 的存储是分开的，在主屏幕应用里设置一次即可 |
| 专注结束没有响 | 提示音只在应用开着时会响；锁屏后计时照常按真实时间算，回到应用时自动结算 |
